# Real-Time Traffic Density Estimation using YOLOv8

## Overview
This project uses YOLOv8 and OpenCV to analyze real-time traffic from video streams.

## Features
- Real-time vehicle detection
- Traffic density estimation
- Lane-wise vehicle monitoring
- Video stream processing

## Tech Stack
- Python
- YOLOv8
- OpenCV
- NumPy

## Project Demo
The system detects vehicles in traffic videos and classifies traffic intensity as Smooth or Heavy.
